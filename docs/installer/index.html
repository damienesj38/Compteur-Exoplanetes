Installer le compteur d'exoplanètes

Pour l'écran Elecrow CrowPanel Advance 7" (ESP32-S3). L'installation prend une minute et se fait directement depuis cette page.

Avant de commencer

  1. Utilise Chrome ou Edge sur un ordinateur (pas sur téléphone, pas avec Firefox ni Safari).
  2. Branche l'écran à l'ordinateur avec le câble USB-C fourni.
  3. Regarde le numéro de version imprimé sur la carte, au dos de l'écran (par exemple « V1.4 »).

Installer

Carte V1.3, V1.4 ou V1.5

Le cas le plus courant (cartes vendues actuellement).

Ce navigateur ne permet pas l'installation : utilise Chrome ou Edge sur ordinateur. L'installation nécessite une page sécurisée (https).
Carte V1.2

Uniquement si « V1.2 » est imprimé sur la carte.

Ce navigateur ne permet pas l'installation : utilise Chrome ou Edge sur ordinateur. L'installation nécessite une page sécurisée (https).
  1. Clique sur Installer sur mon écran, puis choisis le port qui contient CH340 ou USB-SERIAL dans la liste.
  2. Accepte d'effacer l'écran et lance l'installation. Ne débranche rien tant que ce n'est pas terminé.
  3. À la fin, l'écran redémarre et affiche « Bienvenue ! ». Avec ton téléphone, connecte-toi au Wi-Fi Compteur-Exoplanetes, choisis ton Wi-Fi, tape son mot de passe et ta ville, puis enregistre.

En cas de souci

  1. Aucun port dans la liste : essaie un autre câble ou une autre prise USB. Si rien n'apparaît, installe le pilote CH340 du fabricant WCH, puis recommence.
  2. Écran noir après l'installation : tu as peut-être choisi la mauvaise version de carte. Recommence avec l'autre bouton.
  3. Changer de Wi-Fi ou de ville : appuie 5 secondes sur l'écran, puis choisis « Oui ».
  4. Les mises à jour suivantes arrivent toutes seules par Wi-Fi : inutile de revenir sur cette page.

Données : exoplanet.eu (Observatoire de Paris), Launch Library 2 (The Space Devs), JPL Horizons (NASA), Météo-France via Open-Meteo, 7Timer!. Voir les données du jour.
